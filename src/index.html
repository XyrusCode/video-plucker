    Site cookies

    Import a cookies.txt per site so yt-dlp can download age-restricted or private content. A profile named after a site serves any URL containing it, so x covers x.com and twitter.com.

    Export and import

    Move your settings, site logins and download queue between this machine and the Android app, or between two computers. A dump contains live login cookies, so keep the file private. Importing replaces any cookie set with the same name, and a parked playlist comes back as a single item.
