      Cookies

      Import a cookies.txt file per site so yt-dlp can download age-restricted or private content. A profile named after a site serves any URL containing it, so x covers x.com and twitter.com.

      Backup & Restore

      Export your settings, site logins and download queue to a file, then import it on another machine. The desktop and Android apps read the same format, so a dump moves between either one. The dump contains live login cookies; keep the file private. Importing replaces any cookie set with the same name, and a queued playlist comes back as a single item.
